# AgentOps v0.4.4: Human-in-the-Loop Approval Architecture

## Overview
Milestone **v0.4.4** implements the **Human-in-the-Loop Approval Workflow**, enabling safe operator review, time-to-live expiration, request binding, and single-use replay protection for remediation actions.

```
                    SRE Agent
                       │
                 ActionRequest  (action, target, reason, evidence_refs)
                       │
                       ▼
               Security Gateway
                       │
                       ▼
                 Policy Engine   (Evaluates policy -> REQUIRE_APPROVAL)
                       │
                       ▼
                ApprovalManager  (Creates ApprovalRequest, status=PENDING, TTL=900s)
                       │
                       ▼
              SQLite Storage (data/agentops.db)
                       │
                       ▼
                 Human Operator  (agentops approvals approve <id> --operator alice.sre)
                       │
                       ▼
                Status: APPROVED
                       │
                       ▼
               Security Gateway  (execute_approved_action)
                       ├── 1. Check approval is APPROVED and NOT expired
                       ├── 2. Verify exact request binding (action, target, evidence)
                       ├── 3. Re-evaluate live policy & capabilities
                       ├── 4. Transition status: APPROVED -> CONSUMED
                       └── 5. Execute safe callback
```

## 1. Approval State Machine

```
              ┌───────────────┐
              │    PENDING    │
              └───┬───┬───┬───┘
                  │   │   │
        ┌─────────┘   │   └─────────┐
        ▼             ▼             ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ APPROVED │  │ REJECTED │  │ EXPIRED  │
  └────┬─────┘  └──────────┘  └──────────┘
       │
       ▼ (Single-use execution)
  ┌──────────┐
  │ CONSUMED │
  └──────────┘
```

## 2. Database Schema (`data/agentops.db`)

### `approvals` Table
| Column | Type | Description |
|---|---|---|
| `approval_id` | TEXT PRIMARY KEY | Unique approval identifier (`appr-xxxxxxxx`) |
| `request_id` | TEXT | Linked ActionRequest ID (`req-xxxxxxxx`) |
| `status` | TEXT | `PENDING`, `APPROVED`, `REJECTED`, `EXPIRED`, `CONSUMED` |
| `action` | TEXT | Capability action (`k8s.remediation.restart_deployment`) |
| `action_request_json` | TEXT | Full serialized ActionRequest payload |
| `policy_decision_json`| TEXT | Full serialized PolicyDecision payload |
| `requested_at` | TEXT | ISO 8601 UTC creation timestamp |
| `expires_at` | TEXT | ISO 8601 UTC expiration timestamp |
| `decided_at` | TEXT | ISO 8601 UTC operator decision timestamp |
| `decided_by` | TEXT | Operator identifier (e.g. `alice.sre`) |
| `decision_reason` | TEXT | Human operator justification |
| `consumed_at` | TEXT | ISO 8601 UTC timestamp when executed |

### `approval_records` Table (Audit Trail)
| Column | Type | Description |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | Autoincrement record ID |
| `approval_id` | TEXT | Approval ID |
| `request_id` | TEXT | ActionRequest ID |
| `operator_id` | TEXT | Operator ID (or NULL for auto-expiration) |
| `decision` | TEXT | `APPROVE`, `REJECT`, `EXPIRE`, `CONSUME` |
| `previous_status` | TEXT | Previous state |
| `new_status` | TEXT | New state |
| `reason` | TEXT | Transition rationale |
| `timestamp` | TEXT | ISO 8601 UTC timestamp |

## 3. Operator CLI Workflow

```bash
# 1. List pending approvals
agentops approvals list --pending

# 2. Show detailed approval request (with reason, evidence, policies)
agentops approvals show appr-a1b2c3d4

# 3. Approve request
agentops approvals approve appr-a1b2c3d4 --operator alice.sre --reason "Approved for crash recovery"

# 4. Reject request
agentops approvals reject appr-a1b2c3d4 --operator alice.sre --reason "Incorrect target workload"
```
