# AgentOps v0.5: Controlled Kubernetes Remediation Architecture

## Overview
Milestone **v0.5** implements **Controlled Kubernetes Remediation**, introducing 3 narrowly scoped, policy-governed, human-approved write tools with pre-remediation snapshots and post-remediation verification.

```
                         ┌─────────────────────┐
                         │      SRE Agent      │
                         └──────────┬──────────┘
                                    │
                              ActionRequest  (action, target, reason, evidence_refs)

                                    ▼
                         ┌─────────────────────┐
                         │    Policy Engine    │
                         └──────────┬──────────┘
                                    │
                           REQUIRE_APPROVAL
                                    │
                                    ▼
                         ┌─────────────────────┐
                         │  Human Approval     │
                         └──────────┬──────────┘
```

## 1. Controlled Remediation Tools (MCP)

| MCP Tool Name | Capability Name | Purpose | Safe Bounds |
|---|---|---|---|
| `k8s_restart_deployment` | `k8s.remediation.restart_deployment` | Controlled rolling restart for crash recovery | Deployment scoped |
| `k8s_scale_deployment` | `k8s.remediation.scale_deployment` | Horizontal replica adjustment | `replicas: 1-10`, policy `max_replicas: 3-5` |
| `k8s_rollback_deployment` | `k8s.remediation.rollback_deployment` | Rollout undo to stable revision | Deployment scoped, valid revision numbers |

## 4. Remediation CLI Commands

```bash
# 1. Dry-run planning
agentops remediate restart --namespace demo --deployment demo-app --dry-run

# 2. Execute approved restart
agentops remediate restart --namespace demo --deployment demo-app --approval-id appr-90a1b2c3

# 3. Controlled scaling
agentops remediate scale --namespace demo --deployment demo-app --replicas 3 --approval-id appr-90a1b2c3

# 4. Controlled rollback
agentops remediate rollback --namespace demo --deployment demo-app --revision 1 --approval-id appr-90a1b2c3
```
