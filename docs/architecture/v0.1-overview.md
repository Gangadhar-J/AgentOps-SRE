# Architecture Overview (v0.1)

## Purpose
Milestone **v0.1** establishes the foundational local infrastructure layer for the **AgentOps-SRE** platform. It provides a local Kubernetes cluster, a failure-prone demo application, and a lightweight observability stack (Prometheus, Loki, Grafana Alloy, Grafana) capable of generating and recording telemetry during incidents.

## Telemetry Correlation Strategy
To enable the future AI SRE agent (v0.2+) to connect symptoms across data sources, the foundation guarantees consistent label taxonomy across layers:

1. **Kubernetes Identity**: `namespace`, `pod`, `container`, `app`, `service`, `node`
2. **Prometheus Metrics**: Scrape job relabels pod annotations to standard labels: `namespace="demo"`, `pod="demo-app-..."`, `app="demo-app"`
3. **Structured Logs**: Application outputs JSON with explicit fields: `request_id`, `service`, `namespace`, `pod`, `node`, `endpoint`, `status_code`, `error_type`
4. **Log Labels**: Alloy automatically enriches container logs with `namespace`, `pod`, `container`, `app`
