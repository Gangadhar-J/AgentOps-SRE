# AgentOps v0.2: AI SRE Agent Architecture

## Overview
Milestone **v0.2** introduces a controlled, AI-assisted SRE investigation system that collects multi-modal telemetry from Kubernetes, Prometheus, and Grafana Loki, normalizes the evidence, and utilizes an LLM provider to synthesize an evidence-backed Root Cause Analysis (RCA).

## 1. Telemetry Collection & Evidence Taxonomy

### Telemetry Pipeline
1. **Kubernetes API**: Pod lifecycle phases, container restart counts, last termination reason (`OOMKilled`, `Error`), exit codes (137, 1), and warning events (`BackOff`, `Unhealthy`).
2. **Prometheus**: HTTP request rates, 5xx error rate percentages (`sum(rate(http_requests_total{status=~"5.."}))`), and synthetic memory leak gauges (`app_memory_allocated_bytes`).
3. **Loki**: Structured JSON application logs, error types (`DatabaseConnectionTimeout`, `FatalProcessCrash`, `MemoryError`), and stack traces.

### Evidence Taxonomy
- **`FACT`**: Directly measured telemetry, log line, or API status (e.g. `Pod restart count = 3`, `HTTP 500 error rate = 50.0%`).
- **`INFERENCE`**: Derived conclusion connecting multiple facts (e.g. `Readiness probe failure correlated with 500 status on /orders`).
- **`HYPOTHESIS`**: Proposed root cause awaiting verification.

Every evidence item receives a sequential, immutable identifier (`E001`, `E002`, `E003`...).

## 3. Provider-Agnostic LLM Layer

The `BaseLLMProvider` interface supports:
- **`MockRuleBasedLLMProvider`**: Deterministic scoring engine for reproducible CI testing without requiring API keys or network calls.
- **`GeminiLLMProvider`**: Integration with Google Gemini (`gemini-2.5-flash`) via structured JSON schema mode.
- **`OpenAILLMProvider`**: Compatible with OpenAI models and local Ollama instances.
